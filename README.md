# Mosque Accounting & Ledger App (Offline)

## APK বানানোর নির্দেশনা:
1. এই ZIP ফোল্ডারের ভেতরে থাকা `index.html` ফাইলটি GitHub Repository-তে আপলোড করুন অথবা সরাসরি APK কনভার্টারে ব্যবহার করুন।
2. WebIntoApp (webintoapp.com) বা Website 2 APK Builder-এ গিয়ে "Local HTML" অপশন সিলেক্ট করে এই `index.html` ফাইল (বা ZIP ফাইলটি) আপলোড করুন।
3. APK বিল্ড করার সময় **Enable File Downloads / Storage Permission** অপশনটি চালু রাখুন, যাতে ফোনের Downloads ফোল্ডারে সরাসরি PDF এবং Excel (.xlsx) ফাইল সেভ হয়।
